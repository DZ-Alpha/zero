## 5. 네임스페이스 확정 — 16개, 전부 `-ns`

**규칙: `dang-<약칭|제품명>-ns`** — 앱 계층은 약칭(fe/be/pl/db), 인프라는 제품명.

| 네임스페이스 | tier | enforce | 판단 근거 |
| --- | --- | --- | --- |
| `dang-fe-ns` | frontend | restricted | Q1 NO / Q2 NO |
| `dang-be-ns` | backend | restricted | Q1 NO / Q2 NO |
| `dang-pl-ns` | pipeline | restricted | vision-worker·crawler 등 7종 |
| `dang-db-ns` | database | **baseline** | Q2 YES — 공식 이미지가 root로 시작 |
| `dang-kafka-ns` | database | restricted | ⚠️ 이미지 확정 후 재확인 |
| `dang-obsv-ns` | observability | restricted | 수집·저장·시각화 |
| `dang-obsv-agent-ns` | observability | **privileged** | ★ **Q1 YES** — hostPath |
| `dang-vault-ns` | security | restricted | ⚠️ `disable_mlock: true` 전제 |
| `dang-cert-manager-ns` | security | restricted | |
| `dang-kyverno-ns` | security | restricted | |
| `dang-sealed-secrets-ns` | security | restricted | |
| `dang-istio-ns` | network | **privileged** | ★ istio-cni DaemonSet |
| `dang-cloudflared-ns` | network | restricted | |
| `dang-argocd-ns` | cicd | restricted | 윤경님 담당, ns만 선생성 |
| `dang-longhorn-ns` | storage | **privileged** | ★ 블록 디바이스 접근 |
| `dang-velero-ns` | storage | baseline | ⚠️ node-agent 쓰면 privileged |

**시방서 @NameSpace 탭에서 개명 필요**: `dang-front`→`dang-fe-ns`, `dang-backend`→`dang-be-ns`,
`dang-pipeline`→`dang-pl-ns`, `dang-data`→`dang-db-ns`, `dang-kafka`→`dang-kafka-ns`,
`dang-cloudflared`→`dang-cloudflared-ns`
