# K8s 9일 실행계획 — 이해가 남는 방식으로

> 2026-07-27 ~ 08-04 · 김지훈 · 보안·모니터링
> **목표 두 개**: ① 깊이 있게 구축·적용한다 ② **안 보고 설명할 수 있다**
> 이 문서는 산출물 계획이 아니라 **작업 방식 계약서**입니다.

---

## 0. 진단 — 왜 안 남았나

지금까지는 **완성본을 먼저 받아서 읽는** 방식이었습니다. 문제는 이겁니다:

> 완성된 결과물을 읽으면 **"이해했다"는 느낌**은 생깁니다. 그런데 그건 **인식(recognition)** 이지 **인출(recall)** 이 아닙니다.

| | 인식 | 인출 |
| --- | --- | --- |
| 언제 되나 | 답을 **보면** 맞다는 걸 안다 | 답을 **안 보고** 만들어낸다 |
| 느낌 | "아 이거 알지" | 막히면 바로 티가 난다 |
| 발표에서 | **쓸모없음** | 이것만 쓸모있음 |

**읽어서 생긴 인식은 발표장에서 인출로 바뀌지 않습니다.** 그래서 방식을 바꿉니다.

---

## 1. 작업 방식 4가지 변경 (오늘부터 적용)

### 변경 ① 선(先)설명 → 후(後)구축

**바뀌기 전**: "NetworkPolicy YAML 써줘" → 완성본 받음 → 읽음 → 적용
**바뀐 후**: 오브젝트를 다루기 전에 **지훈님이 먼저 말합니다.**

> "이게 뭘 하는 건지, 왜 필요한지, 안 쓰면 어떻게 되는지 제가 아는 대로 말해볼게요."

→ 제가 듣고 **틀린 부분만** 교정합니다. **맞는 부분은 설명하지 않습니다.**

**시간**: 오브젝트당 5분. 하루 15~20분.
**왜 효과 있나**: 말해보면 **모르는 지점이 정확히 어디인지** 드러납니다. 읽을 땐 안 드러납니다.

### 변경 ② 지훈님이 쓰고, 제가 리뷰

**바뀌기 전**: 제가 YAML 완성본 → 붙여넣기
**바뀐 후**:
1. 제가 **뼈대만** 줍니다 — 필드 이름만 있고 값은 `___`
2. 지훈님이 값을 채웁니다
3. 제가 리뷰하고 **틀린 이유를 설명**합니다
4. 적용

**예시**:
```yaml
apiVersion: ___          # 힌트: networking.k8s.io — 왜 core가 아닐까?
kind: NetworkPolicy
metadata:
  name: ___
  namespace: ___
spec:
  podSelector: ___       # 이 정책이 "누구를" 격리하는가
  policyTypes: [___]     # 이걸 빼면 egress는 어떻게 되나?
  ingress:
    - from: [___]
```

**시간**: 완성본 받는 것보다 오브젝트당 10~15분 더 걸립니다. **그 시간이 이해입니다.**

**⚠️ 예외**: 시간에 쫓기는 긴급 상황에서는 제가 완성본을 줍니다. **단, 준 다음에 반드시 5분 워크스루**를 합니다. 이해는 산출물의 **조건**이지 대체물이 아닙니다.

### 변경 ③ 일부러 부순다

각 오브젝트를 적용한 **직후**, 그걸 **틀리게 만들어 봅니다.**

| 오브젝트 | 부수는 방법 | 확인할 것 |
| --- | --- | --- |
| PSA | 하드닝 없는 파드 배포 | apply는 성공, replica 0 |
| RBAC | RoleBinding 지우고 `auth can-i` | yes → no |
| NetworkPolicy | DNS egress 예외 빼기 | 이름 해석부터 실패 |
| ResourceQuota | requests 없는 파드 배포 | 거부 메시지 |
| LimitRange | limit만 주고 배포 | request가 limit과 같아짐 |
| probe | liveness 실패 조건 만들기 | 재시작 카운트 증가 |

**순서가 중요합니다**: ① 무슨 에러가 날지 **먼저 예측**하고 ② 실행하고 ③ 맞았는지 확인

**예측이 맞으면 이해한 것이고, 틀리면 그 지점이 구멍입니다.**

**시간**: 오브젝트당 5분, 하루 20~30분.
**부수적 이득**: 여기서 나온 에러 화면이 **그대로 발표 자료**가 됩니다. 따로 찍을 필요가 없습니다.

### 변경 ④ 매일 마감 회상 테스트

하루 끝에 **자료를 안 보고** 3문항에 답합니다. 제가 채점합니다.

- 답이 나오면 → 넘어감
- 막히면 → **그날 그 부분은 안 배운 것**. 다음날 첫 15분에 재시도

**시간**: 10분.

## 7. 제가 지킬 것

- **완성본을 먼저 주지 않습니다.** 뼈대 + 힌트 → 지훈님이 채움 → 리뷰
- **맞는 부분은 설명하지 않습니다.** 틀린 것과 빠진 것만 짚습니다
- **매일 마감에 회상 테스트를 먼저 냅니다.** 요청을 기다리지 않습니다
- **모든 주장에 공식문서 근거를 답니다.** 제 기억으로 단정하지 않습니다
- **긴급 예외를 쓸 때는 명시적으로 말합니다** — "지금은 시간이 없어 완성본을 드립니다. 워크스루는 X시에 하겠습니다"
